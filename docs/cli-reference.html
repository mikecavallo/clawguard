CLI Reference

Complete reference for every ClawGuard command, option, and exit code.

$ clawguard <command> [options]

scan

Scan a skill directory for security issues. Runs static analysis, dependency scanning, and prompt injection detection by default. Includes semantic analysis when an AI provider is configured.

Usage

clawguard scan <path> [options]

Arguments

ArgumentDescription
pathPath to skill directory or URL (GitHub repos supported)

Options

FlagDescription
-f, --fastStatic analysis only (skip semantic analysis)
-s, --sandboxInclude behavioral sandbox analysis (requires Docker)
-d, --deepDeep dependency source analysis
-o, --output <format>Output format: md (default), json, html
-v, --verboseShow detailed progress
--api-key <key>API key for semantic analysis (prefer env vars)

Examples

$ clawguard scan ./my-skill
$ clawguard scan ./my-skill --fast
$ clawguard scan ./my-skill --sandbox -o json
$ clawguard scan https://github.com/user/skill-repo

full

Run all analysis layers including semantic analysis and sandbox. Equivalent to scan --sandbox with semantic always enabled.

Usage

clawguard full <path> [options]

Options

Same as scan. Semantic and sandbox are enabled by default.

Examples

$ clawguard full ./suspicious-skill
$ clawguard full ./skill -o json

gate

Pre-install security gate for CI/CD pipelines. Returns exit code 0 if safe, exit code 2 if blocked. Designed to be placed before npm install or skill installation.

Usage

clawguard gate <path|url> [options]

Options

FlagDescription
-s, --sandboxInclude behavioral sandbox analysis
--allow-highOnly block on critical findings (allow high through)
--jsonOutput JSON result for programmatic use

Exit Codes

CodeMeaning
0ALLOWED — safe to install
2BLOCKED — critical (or high, unless --allow-high) issues found

Examples

# Block on critical or high
$ clawguard gate ./skill && npm install

# Block only on critical
$ clawguard gate ./skill --allow-high

# JSON output for CI
$ clawguard gate ./skill --json | jq '.allowed'

# Gate a remote skill
$ clawguard gate https://github.com/user/skill

library

Scan an entire directory of skills for attack chains. Analyzes how skills interact and identifies dangerous capability combinations.

Usage

clawguard library <path> [options]

Options

FlagDescription
-f, --fastPattern analysis only (skip semantic chain analysis)
-o, --output <format>Output format: md, json
-v, --verboseShow detailed progress

Examples

$ clawguard library ~/.skills/
$ clawguard library ./my-skills --fast -o json

graph

Generate a data flow and capability graph for a skill library. Visualizes how data and capabilities flow between skills.

Usage

clawguard graph <path> [options]

Options

FlagDescription
-o, --output <format>Output format: md, json

Examples

$ clawguard graph ~/.skills/

honeypot

Run only the honeypot/sandbox analysis on a skill. Useful when you want to test a skill's runtime behavior without running the full scan pipeline.

Usage

clawguard honeypot <path>

Examples

$ clawguard honeypot ./suspicious-skill

config

Configure the AI provider and API key for semantic analysis. Runs an interactive setup wizard.

Usage

clawguard config [options]

Options

FlagDescription
--showDisplay current configuration
--testTest API connection
--clearReset configuration

Examples

$ clawguard config          # Run setup wizard
$ clawguard config --show   # View current config
$ clawguard config --test   # Verify API works
$ clawguard config --clear  # Reset to default

init

Initialize a new skill with security best practices. Creates a template SKILL.md and recommended project structure.

Usage

clawguard init [path]

Examples

$ clawguard init ./my-new-skill

sign

Cryptographically sign a skill to verify its integrity. Creates a signature that can be verified before installation.

Usage

clawguard sign <path> [options]

Examples

$ clawguard sign ./my-skill

diff

Compare two versions of a skill and highlight security-relevant changes. Useful for reviewing skill updates before installing new versions.

Usage

clawguard diff <path-a> <path-b>

Examples

$ clawguard diff ./skill-v1 ./skill-v2

reputation

Check the reputation of a skill or author against the community database. Shows known reports and trust scores.

Usage

clawguard reputation <path|author>

Examples

$ clawguard reputation ./some-skill
$ clawguard reputation user123

monitor

Start a continuous monitoring daemon that watches a skill directory for changes and re-scans automatically.

Usage

clawguard monitor <path> [options]

Examples

$ clawguard monitor ~/.skills/

dashboard

Start a local web dashboard that displays scan results, trends, and security status for your skill library.

Usage

clawguard dashboard [options]

Examples

$ clawguard dashboard

update-patterns

Fetch the latest detection patterns from the ClawGuard GitHub repository. Updates code.yaml, deps.yaml, and prompt.yaml with the latest community patterns.

Usage

clawguard update-patterns

Examples

$ clawguard update-patterns
Fetching latest patterns from GitHub...
  code.yaml:   42 patterns (was 36, +6 new)
  deps.yaml:   118 packages (was 100, +18 new)
  prompt.yaml: 35 patterns (was 30, +5 new)
Patterns updated successfully.

ui

Launch the interactive terminal UI. Provides a full-screen, menu-driven interface for scanning skills, checking the known-bad database, and configuring providers.

Usage

clawguard ui

Menu Options

KeyAction
[1]Scan local skill(s)
[2]Scan skill from URL
[3]Check known-bad database
[4]Configure AI provider
[5]View scan history
[q]Quit

Display the full ClawGuard overview including why it exists, how it protects you, and all available features.

Usage

clawguard about

Exit Codes

ClawGuard uses consistent exit codes across all commands:

Code Meaning Context
0 Success / Safe No issues found, or risk within threshold
1 High risk / Error High-risk findings or fatal error
2 Blocked / Critical Critical findings detected (used by gate)
CI/CD Tip

Use clawguard gate in your pipeline. It returns exit code 0 (safe to proceed) or 2 (block installation), making it straightforward to integrate into any CI/CD system.
