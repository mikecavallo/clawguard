The Agent Threat Landscape

AI agents can install and run skills — code that extends their capabilities. But this creates a massive attack surface.

🔑

Credential Theft

Skills that look helpful but steal your SSH keys, AWS credentials, and API tokens.

💬

Prompt Injection

Hidden instructions that hijack agent behavior — "ignore previous rules" attacks embedded in skills.

🔗

Attack Chains

Multiple "innocent" skills that combine to form credential exfiltration pipelines.

🎭

Social Engineering

Skills that manipulate the agent to bypass its own safety rules and expose sensitive data.

📦

Supply Chain Attacks

Typosquatted packages, compromised dependencies, and malicious install scripts hiding in your skill's node_modules.
